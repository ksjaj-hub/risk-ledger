Open event risks

AFMX tracks what is still unresolved after the headlines move on. Each card says what would have to be true for the risk to count as resolved. Those conditions were written on the date shown, before the outcome was known. Good news that does not meet them is listed too.

How to check that nothing here was changed afterwards

  1. Every record is its own dated commit in a public history.
  2. Each record contains the fingerprint (SHA-256) of the record before it, so one edit would break the chain.
  3. Records carry OpenTimestamps proofs anchored to the Bitcoin blockchain.
  4. The judging rule is published and versioned. Old versions are never edited.
