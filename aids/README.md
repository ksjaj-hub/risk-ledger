# Reading aids

`reading.json` helps the public page show what matters first. It is editorial and changes freely;
it is **not** part of the record.

- `featured`: up to three cards shown in full at the top. Chosen at the weekly review: a card with a
  date coming up, a card whose status changed, or the most recent event.
- `dates`: dated deadlines that a card's own sources state. Only dates found in the card's sources go here.
- `exposure`: tickers and ETFs that the event plausibly touches, by sector or by being named in the card.
  This is AFMX's own mapping for navigation. It is not a statement about what any security will do and
  not a recommendation. When a card is added, add its entry here.
